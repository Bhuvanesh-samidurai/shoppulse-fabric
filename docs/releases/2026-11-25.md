## Rollout
1. Bhuvanesh merges the release PR into `main`.
2. `deploy / test` runs `sp-ci-test`: deploy, DDL notebooks, smoke test, integration tests.
3. `deploy / prod` **waits for Bhuvanesh's approval** (GitHub Environment `prod`), then does the same in `shoppulse-*-prod` as `sp-ci-prod`.
4. After Test: re-run `infra/bootstrap/grant_read.py` so agents can read Test lakehouses (#18).

## Rollback
- **Items:** revert the release merge on `main`. The next deploy unpublishes non-data items.
- **Data items:** never auto-deleted.
- **Tables:** empty at this point, so there's nothing to restore.
